# 賃貸管理士 合格ドリル

2026年度 賃貸不動産経営管理士試験（2026年11月15日）向けの学習用PWAです。`index.html` をブラウザで開くだけで使えます。GitHub Pagesへのpushで自動公開すれば、スマートフォンのホーム画面に追加できます。

## 収録内容

- 予想模試 50問（学習モード／120分の本番モード・自動採点・分野別成績）
- ○×ドリル 146問（★★★最優先項目を問題化。苦手・未回答・分野別出題）
- 要点まとめ（重要ポイント59項目・★★★詳細146項目・数字まとめ46項目、検索とチェック機能つき）

内容は `賃貸不動産\2026_賃貸不動産経営管理士_予想問題.xlsx` と同じです。問題はオリジナルの予想問題です。法改正・試験情報は公式発表と最新テキストで確認してください。

## GitHub Pagesで公開

1. GitHubにこのアプリのフォルダーをルートとする専用リポジトリを作成します。
2. アプリのファイル一式（`.github`フォルダーを含む）をリポジトリにpushします。`main`または`master`ブランチへのpushでデプロイが始まります。
3. GitHubのリポジトリで **Settings > Pages** を開き、公開元を **GitHub Actions** にします。
4. **Actions** タブでデプロイ完了を確認し、表示されたPages URLをスマートフォンで開きます。

公開リポジトリのGitHub Pagesは、URLを知っている人なら誰でも見られます。

## スマートフォンに追加

- iPhone: SafariでPages URLを開き、共有メニューから「ホーム画面に追加」します。
- Android: ChromeでPages URLを開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

## データの取り扱い

学習記録（解答・正誤・チェック）は端末のブラウザ内（localStorage）にだけ保存され、外部には送信されません。ブラウザのデータを消去すると記録も消えます。PCとスマートフォンなど、端末間で記録は共有されません。
